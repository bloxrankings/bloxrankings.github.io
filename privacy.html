Privacy Policy

Blox Rankings Uploader · Last updated: November 20, 2026

Blox Rankings Uploader ("the tool") is a personal tool used only by the owner of the Blox Rankings YouTube channel to manage that channel. It has no other users.

Google user data the tool accesses

  • YouTube Data API (scopes youtube.upload, youtube.readonly, youtube.force-ssl): uploading the owner's videos, adding caption tracks, adding videos to the owner's playlist, setting publish schedules, and reading basic statistics of the owner's videos and public video search results.
  • Google Cloud Text-to-Speech (scope cloud-platform): turning the owner's scripts into narration, billed to the owner's own Google Cloud project.

How the data is used and stored

Data is used only to perform the actions above for the owner's own channel. Sign-in tokens and working files are stored only on the owner's own computer. The tool has no server, does not sell, share or transfer Google user data to anyone, and does not use it for advertising.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local token files also removes the tool's stored access.

Contact

Questions about this policy can be sent through the Blox Rankings YouTube channel.
